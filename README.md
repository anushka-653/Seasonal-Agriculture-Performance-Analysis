# Seasonal Agriculture Performance Analysis

A data analysis project that explores agricultural performance across **Kharif, Rabi, and Zaid** seasons.

## Overview

This project analyzes crop yield, production, profit, water efficiency, environmental factors, and disease/pest risk to identify seasonal and regional patterns.

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Includes

* Seasonal yield & production comparison
* Profit, revenue & cost analysis
* Water usage & efficiency
* Rainfall, temperature & soil moisture analysis
* Fertilizer and yield relationship
* Disease/pest risk analysis
* Crop-wise performance
* State-wise seasonal comparison

## Key Findings

* **Kharif** shows the strongest overall performance.
* **Sugarcane** has the highest average yield and profit.
* **Zaid** shows the weakest overall performance.
* Seasonal performance varies across states.
* Soil moisture has almost no linear relationship with yield in this dataset.
